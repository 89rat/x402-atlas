## Protocol learnings (feed back into adapters)
1. **New ecosystem pattern observed**: GET on a paid path returns HTTP 200 "buyer metadata" (free pre-payment JSON with price/terms); POST triggers the actual 402. Prober now handles this. → Watch for other sites adopting this pattern; consider a dedicated adapter name (`buyer-contract-v1`).
2. **Manifest schema variance**: real manifests use `resources[]` (URIs, sometimes with `#fragment` tool names), not `endpoints[{path}]`. Parser handles both.
3. **Wire amounts are integer unit strings** ("5000" = $0.005) — confirmed vs tx 0xc647…672d. Bug caught by contract tests (decimal-padding inflated ×10⁶).
4. Several seed domains from research are dead/404 (superhighway.xyz, bismuth.ai, kaisha.dev at time of probe) — seed list needs curation from live sources, not blog posts.
